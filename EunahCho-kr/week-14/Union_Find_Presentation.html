개념

서로소 집합 (Disjoint Set)

서로 공통 원소가 없는 부분 집합들. Union-Find는 이런 집합들을 빠르게 합치고, 어떤 원소가 어느 집합에 속하는지 찾는 알고리즘이에요.

{1, 2}, {3, 4} 서로소 O

1 2
3 4

{1, 2}, {2, 4} 서로소 X

1 2   
     4

2가 두 집합에 동시에 속함

자료구조

집합 하나 = 트리 하나

  • 각 원소는 부모 노드를 가리키는 화살표 하나만 가짐
  • 트리의 루트 = 그 집합의 대표값
    왼쪽은 집합 {1,2,3,4}, {5,6} — 대표는 1과 5
  • 그래서 배열 parent 한 줄이면 전체를 표현할 수 있음
  • 루트는 자기 자신을 부모로 가짐
    parent[1] = 1, parent[5] = 5
구현

연산은 딱 세 개

init(n)
모든 원소를 자기 자신만 있는 집합으로

def init(n):
    parent = [i for i in
              range(n + 1)]
    return parent

find(x)
부모를 따라 올라가 루트(대표)를 찾음

def find(x):
    if parent[x] != x:
        return find(parent[x])
    return x

union(x, y)
두 루트를 찾아, 한쪽을 다른 쪽 밑에 붙임

def union(x, y):
    x = find(x)
    y = find(y)
    if x > y:
        parent[x] = y
    else:
        parent[y] = x
규칙: 두 루트 중 번호가 더 작은 쪽이 대표가 됨. 같은 집합인지 확인하려면 find(a) == find(b)

Union-Find 과정 한 단계씩 따라가기 · → 키로 진행

문제점

트리가 한쪽으로 길어지면?

union(4,5) → union(3,4) → union(2,3) → union(1,2)
순서로 합치면 일자로 늘어진 편향 트리가 생김

  • find(5)는 5 → 4 → 3 → 2 → 1, 모든 노드를 거쳐야 루트 도착
  • 노드가 N개면 find 한 번에 O(N)
  • 파이썬은 재귀 한도가 1000 → 깊으면 RecursionError
해결책: find 하면서 지나간 노드들을 루트에 바로 붙여버리자 → 경로 압축

경로 압축 올라갈 땐 루트를 찾고, 돌아올 땐 루트에 붙인다

def find(x):
if parent[x] != x:
parent[x] = find(parent[x])
return parent[x]
코드 비교

바뀐 건 단 한 줄

기본 find

def find(x):
    if parent[x] != x:
        return find(parent[x])    return x

경로 압축 find

def find(x):
    if parent[x] != x:
        parent[x] = find(parent[x])    return parent[x]
  • 찾은 루트를 그냥 반환만 하지 않고 parent[x]에 저장해 둠
  • 재귀가 풀리면서 경로 위 모든 노드가 루트를 직접 가리키게 됨
  • 한 번 압축되면 다음 find는 한 칸만에 루트 도착
