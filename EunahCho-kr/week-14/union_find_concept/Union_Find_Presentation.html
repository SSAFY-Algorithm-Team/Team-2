개념

서로소 집합 (Disjoint Set)

서로 공통 원소가 없는 부분 집합들. Union-Find는 이런 집합들을 빠르게 합치고, 어떤 원소가 어느 집합에 속하는지 찾는 알고리즘이에요.

{1, 2}, {3, 4} 서로소 O

1 2
3 4

{1, 2}, {2, 4} 서로소 X

124

2가 두 집합에 동시에 속함

자료구조

집합 하나 = 트리 하나

  • 각 원소는 부모 노드를 가리키는 화살표 하나만 가짐
  • 트리의 루트 = 그 집합의 대표값
    왼쪽은 집합 {1,2,3,4}, {5,6} — 대표는 1과 5
  • 그래서 배열 parent 한 줄이면 전체를 표현할 수 있음
  • 루트는 자기 자신을 부모로 가짐
    parent[1] = 1, parent[5] = 5
헷갈림 주의 · 부모 ≠ 대표
parent에는 바로 위 한 칸만 적어요. 4의 부모는 3, 대표(루트)는 1.
대표를 알려면 4 → 3 → 1 로 끝까지 따라 올라가야 함
→ 그 일을 하는 게 바로 find
구현 · 1 / 3

init(n) 모든 원소를 자기 자신만 있는 집합으로

def init(n):
    # n = 5 → [0, 1, 2, 3, 4, 5]
    parent = [i for i in range(n + 1)]
    return parent
init(5) 직후

회색 점선 칸(0번)은 쓰지 않는 자리

  • Union-Find가 기억할 정보는 딱 하나:
    "각 원소의 부모가 누구인가"
  • 인덱스 = 원소 번호, 값 = 부모 번호
    → 리스트 하나에 숲 전체가 저장됨
  • 처음엔 아직 아무것도 합치지 않았으니
    모두 자기 자신이 부모 = 혼자 있는 집합 N개
  • range(n + 1)인 이유: 원소가 1번부터 시작해서
    0번 칸은 비워두고 번호 = 인덱스로 맞춤
비유 · 반 명부에 "내 조장" 칸이 있다고 생각해 보세요.
아직 조를 안 짰으면 다들 자기 이름을 적어둠.
조를 합칠 때마다 이 칸만 고쳐 쓰면 되니까, 이 명부(parent)가 먼저 있어야 해요.
구현 · 2 / 3

find(x) 부모를 따라 올라가 루트(대표)를 찾음 · 예: find(4)

def find(x):
    if parent[x] != x:          # 루트 아님
        return find(parent[x])  # 부모에게 물어봄
    return x                    # 루트 → 내가 답

find(4)를 호출하면

↓ 올라가기 · "내 대표 누구야?"를 부모에게 떠넘김
find(4)parent[4] = 3 → 루트 아님 → 3에게 물어봄
find(3)parent[3] = 1 → 루트 아님 → 1에게 물어봄
find(1)parent[1] = 1 → 내가 루트! return 1
↑ 돌아오기 · 받은 답을 호출의 반대 순서로 그대로 전달
find(3)받은 1을 그대로 return 1
find(4)받은 1을 그대로 return 1 → 답: 1
  • 멈추는 조건 · parent[x] == x이면 루트에 도착 → x 반환
  • 반복 단계 · 아니면 "내 대표 = 내 부모의 대표"이므로 find(parent[x])로 같은 질문을 부모에게
  • 재귀가 헷갈리면 · while parent[x] != x: x = parent[x] 로 한 칸씩 올라가는 것과 똑같은 일
구현 · 3 / 3

union(x, y) 두 루트를 찾아 한쪽을 다른 쪽 밑에 붙임 · 예: union(4, 6)

def union(x, y):            # union(4, 6)
    x = find(x)             # ① 4→3→1  → x = 1
    y = find(y)             # ② 6→5    → y = 5
    if x > y:               # ③ 1 > 5 ? 아니오
        parent[x] = y
    else:                   #    → else로
        parent[y] = x       # ④ parent[5] = 1
  • 왜 루트끼리 붙일까? 루트를 옮기면 그 밑에 달린 노드(6)가 통째로 따라옴. 원소끼리 parent[4] = 6 하면 4만 떨어져 나가 집합이 쪼개져요
  • 왜 한쪽을 다른 쪽 밑에? 트리 하나엔 루트가 하나뿐이니, 한 루트가 다른 루트의 자식이 되면 합치기 끝
  • 조건 분기의 뜻 · "번호가 작은 루트가 대표" 규칙 → 대표는 늘 그 집합의 최솟값
  • 이미 같은 집합이면 x == y → else에서 parent[x] = x, 아무 변화 없음
합치기 전 · 루트 찾기 (①②)
합친 후 · parent[5] = 1 (④)

Union-Find 과정 한 단계씩 따라가기 · → 키로 진행

def find(x):
if parent[x] != x:
return find(parent[x])
return x
def union(x, y):
x = find(x)
y = find(y)
if x > y:
parent[x] = y
else:
parent[y] = x
find(x) 경로find(y) 경로바뀐 부모
문제점

트리가 한쪽으로 길어지면?

union(4,5) → union(3,4) → union(2,3) → union(1,2)
순서로 합치면 일자로 늘어진 편향 트리가 생김

  • find(5)는 5 → 4 → 3 → 2 → 1, 모든 노드를 거쳐야 루트 도착
  • 노드가 N개면 find 한 번에 O(N)
  • 파이썬은 재귀 한도가 1000 → 깊으면 RecursionError
해결책: find 하면서 지나간 노드들을 루트에 바로 붙여버리자 → 경로 압축

경로 압축 올라갈 땐 루트를 찾고, 돌아올 땐 루트에 붙인다

def find(x):
if parent[x] != x:
parent[x] = find(parent[x])
return parent[x]

  • 한 번 압축되면 다음 find는 한 칸만에 루트 도착

활용

Union-Find는 언제 쓸까?

1같은 집합인지 판별

관계를 하나씩 union으로 합쳐두고, 궁금할 때 find(a) == find(b)로 확인

예) 친구 무리
1–2 친구, 2–3 친구라면
1과 3은 같은 무리일까?
→ union(1,2), union(2,3)
→ find(1) = find(3) = 1 → 같은 무리!

그래프로 말하면 "두 점이 연결돼 있나?"를 빠르게 답하는 것

2사이클 판별

간선을 하나씩 이을 때, 두 끝점이 이미 같은 집합이면 사이클이 생김

1–2, 2–3을 이은 뒤 3–1을 이으려 하면
find(3) = find(1) = 1 → 이미 연결된 사이
→ 또 이으면 고리(사이클)가 생김

3크루스칼 MST

신장 트리 = 모든 점을 사이클 없이 연결한 것 (간선 N−1개)
최소 신장 트리(MST) = 그중 간선 비용 합이 가장 작은 것

예) 마을 잇기
마을 N개를 전부 도로로 연결하되
공사비 합은 최소로!

크루스칼 = 싼 간선부터 고르되, 사이클이 생기면 버림 → 이 사이클 검사를 Union-Find로 함
