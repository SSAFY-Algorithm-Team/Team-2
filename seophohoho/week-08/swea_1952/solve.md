# SWEA 1952 수영장

## 문제 요약

- 이용권은 4종류: 1일권(1일 요금), 1달권(1달 요금), 3달권(3달 연속, 매달 1일 시작), 1년권.
- 1~12월 각 달의 이용 계획(그 달에 수영장 가는 날 수)이 주어진다.
- 총 비용이 최소가 되게 이용권을 조합해서 정답을 출력한다.

## 첫 시도: 3달권을 빼고 계산 (`solve0.py`) — 오답

각 달마다 `min(일수 × 1일권, 1달권)` 으로 최소 비용을 구하고, 12달을 다 더한 뒤 1년권과 비교했다.

- **3달권 자체를 고려하지 않는다.** 3달권이 1달권 3개보다 쌀 수 있는데 그 선택지를 아예 안 본 것.
- TC2 (`10 100 50 300`, 9~12월만 6,2,7,8일)에서 드러난다.
  - solve0: 9월 60 + 10월 20 + 11월 70 + 12월 80 = **230**
  - 정답: 7~9월을 3달권(50) + 10~12월을 3달권(50) = **100**

## 해결: 구간 DP (`solve1.py`)

핵심 아이디어: **"1월부터 i월까지 다 커버하는 최소 비용"** 을 월별로 누적해서 구한다.

`dp[i]` = 1월~i월을 빠짐없이 이용할 수 있는 최소 비용 (`dp[0] = 0`)

i월을 처리하는 방법은 3가지고, 셋 중 제일 싼 걸 고른다.

1. **i월만 1일권으로**: `dp[i-1] + (i월 일수 × 1일권)`
2. **i월만 1달권으로**: `dp[i-1] + 1달권`
3. **i-2, i-1, i월을 3달권으로 묶어서**: `dp[i-3] + 3달권`
   (i가 1, 2월이면 `dp[max(0, i-3)]`으로 0월 이하를 0으로 취급 — 그만큼만 3달권으로 당겨쓰는 셈)

마지막에 `dp[12]`(1년 내내 낱개 이용권으로)와 1년권 중 싼 쪽이 최종 답.

```python
dp = [0] * 13
for i in range(1, 13):
    dp[i] = dp[i-1] + days[i-1] * daily
    dp[i] = min(dp[i], dp[i-1] + monthly)
    dp[i] = min(dp[i], dp[max(0, i-3)] + quarterly)

answer = min(dp[12], yearly)
```

## 왜 3달권이 "연속 구간"인데 그리디로 안 잡히나

3달권을 어느 달부터 끊을지는 전체 조합을 봐야 안다. 예를 들어 7~9월에 끊을지 8~10월에 끊을지에 따라 뒤 구간 비용이 달라진다. `dp[i-3]`이 "그 앞까지의 최적값"을 이미 들고 있기 때문에, 매 i월마다 3달권을 지금 끊는 게 나은지 자동으로 비교된다 — 이게 구간 DP(interval DP)가 그리디보다 안전한 이유다.

## 3달권의 연도 경계 제약은 자동으로 지켜진다

문제 조건상 3달권은 11,12,1월이나 12,1,2월처럼 해를 넘겨서 쓸 수 없다. `dp[i-3] + quarterly`는 배열을 원형(circular)이 아니라 일직선으로만 참조하므로, i가 12를 넘어가는 경우 자체가 없다. 즉 별도 예외 처리 없이 DP 정의만으로 이 제약이 만족된다.

## 시간 복잡도

- 테스트케이스당 월은 12개, 각 월마다 O(1) 비교 3번.
- 테스트케이스 최대 50개 → 총 연산량은 무시할 수준.
